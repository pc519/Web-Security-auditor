# 🛡️ Web Security Auditor

A lightweight, legal Python tool designed to audit website security configurations, check SSL certificate validity, and generate clean HTML reports for site owners.

### ✨ Features
* SSL Certificate Check: Verifies HTTPS connection and calculates remaining days before expiration.
* Security Headers Audit: Scans for critical headers (HSTS, X-Frame-Options, X-Content-Type-Options, CSP, Referrer-Policy).
* Automated HTML Report: Generates a clean, color-coded HTML report ready to be shared with clients.

### 🚀 How to Use
pip install requests
python web_auditor.py

# 🛡️ أداة فحص أمان المواقع

أداة بايثون قانونية وخفيفة مصممة لفحص إعدادات الأمان في المواقع الإلكترونية، والتحقق من صلاحية شهادة الأمان، وتوليد تقارير احترافية جاهزة لأصحاب المواقع.

### ✨ المميزات
* فحص شهادة الأمان: التحقق من الاتصال الآمن وحساب الأيام المتبقية لانتهاء الشهادة.
* فحص ترويسات الحماية: الكشف عن وجود أو غياب أهم إعدادات الحماية ضد هجمات حقن الأكواد واختطاف النقرات.
* توليد تقرير تلقائي: إنشاء ملف تقرير منسق وملون جاهز للتسليم للعملاء.

### ⚠️ إخلاء مسؤولية
هذه الأداة تقوم بفحص سطحي وقانوني للمعلومات العامة المتاحة للمتصفح فقط، وهي مخصصة للأغراض التعليمية والتدقيق الأمني المصرح به.
